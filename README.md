
# 🐾 VetVentures: Online Veterinary Prescription System

**VetVentures** is a full-stack **web application** designed to provide an online platform for **pet owners** to connect with **veterinary doctors** for consultations and digital prescriptions.  
It simplifies pet healthcare management by allowing users to book appointments, receive treatment advice, and download prescriptions — all from the comfort of their home.

---

## 💡 Project Overview

VetVentures bridges the gap between veterinarians and pet owners through a **user-friendly, responsive, and secure web portal**.  
It enables pet owners to consult doctors online, and veterinarians can manage patient data, issue prescriptions, and oversee all activities via an **admin backend**.

This application was developed using **HTML, CSS, JavaScript, Bootstrap, and PHP**, with **MySQL** as the backend database.

---

## 🚀 Features

### 🐕 User (Pet Owner) Features:
- Register and log in securely  
- Submit consultation requests and pet details  
- View and download prescriptions online  
- Track medical history of pets  
- Responsive design for mobile and desktop

### 🩺 Doctor/Admin Features:
- Secure admin login and dashboard  
- Approve, reject, or manage consultations  
- Create and upload digital prescriptions  
- Manage users, doctors, and medical records  
- CRUD operations (Create, Read, Update, Delete)
